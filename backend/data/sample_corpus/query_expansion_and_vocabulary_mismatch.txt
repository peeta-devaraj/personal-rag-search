Vocabulary mismatch occurs when a user's query and a relevant document describe the same concept using different words, causing purely lexical retrieval methods to miss the match entirely. A user searching for "car maintenance tips" will not retrieve a highly relevant document that only ever uses the word "automobile", even though a human reader would immediately recognize the connection.

Query expansion is a classical technique for addressing this problem within a sparse retrieval framework: additional terms related to the original query are added before searching, either from a thesaurus, from co-occurrence statistics mined from the corpus, or via pseudo-relevance feedback, where the top-ranked documents from an initial search are mined for additional query terms and the search is re-run. Dense embedding-based retrieval sidesteps much of this problem by design, since semantically related terms are already mapped close together in the embedding space, which is one of the main motivations for combining sparse and dense retrieval in a hybrid system rather than relying on either alone.
